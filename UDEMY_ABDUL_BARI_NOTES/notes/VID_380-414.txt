master theorem for decreasing functions:-
    T(n)= aT(n-b) + f(n)

    Case 1: a=1
        O( n * f(n) )
    Case 2: a>1
        O( a^n/b * f(n) )
    Case 3: a<1
        O( f(n) )

master theorem for Dividng functions:-
    T(n)= aT(n/b) + n^k * (log n)^p
    
    Case 1: logb a > k
        T(n)= O( n^logb a )
    Case 2: logb a = k
        T(n)= O(f(n) * logn )
    Case 3: logb a < k
        T(n)= O( f(n) )

Divide And Conquer Algorithm
divide the given problem into subproblems 
solve those subproblems
combine all those solutions and get the solution for the main problem
the procedures are recursive in nature
Binary Search uses D&C
Merge Sort uses D&C 

Optimization Problems - problem which as multiple constraints as well as an objective (can be about maximising or minimising the result)
solutions that satisfy the constraints are called feasible problems
out of the feasible solution the one that satisfies the objective is the optimal solution
Greedy Method , Branch and Bound and DP are used for optimization problems
